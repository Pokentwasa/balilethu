# Photos

Upload all your photos straight into this folder. Any file names and any order are fine:
livestock, poultry, deliveries, the farm, the team.

Claude will sort them into the right places on the website.

JPG, PNG or WebP. Photos straight from your phone are fine.

**Logo:** name the file `logo.svg` (or `logo.png`) and it will appear in the menu and footer.
A logo with a transparent background works best.
